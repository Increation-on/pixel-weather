# 🌤️ Pixel Weather App

Простое, но стильное погодное приложение в пиксельном ретро-стиле, построенное на React Native с TypeScript.

## 🎮 Особенности

- **Пиксельный дизайн**: Ретро-стиль с чёткими линиями и палитрой
- **Двойное API**: Использует OpenWeatherMap и WeatherAPI с автоматическим фолбэком
- **React Query**: Кеширование, инвалидация, фоновое обновление
- **TypeScript**: Полная типизация для надёжности
- **Нативные возможности**: Геолокация, push-уведомления, офлайн-режим

## 🛠️ Технологии

- React Native (Expo)
- TypeScript
- NativeWind (Tailwind для React Native)
- React Query (TanStack Query)
- Expo Location, Notifications
- OpenWeatherMap API + WeatherAPI

## 🚀 Быстрый старт

```bash
# Клонирование
git clone https://github.com/YOUR_USERNAME/pixel-weather.git
cd pixel-weather

# Установка зависимостей
npm install

# Запуск
npx expo start
